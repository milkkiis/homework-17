Кроссбраузерность

Простой пример сравнения современного CSS Grid и устаревшего способа построения колонок с помощью float.

Пример макета

CSS Grid

Современный способ создания строк и колонок. В этом примере Grid включается через @supports и подтверждается классом Modernizr .cssgrid.

display: grid;

Float

Старый способ размещения элементов рядом. Здесь он используется как фолбэк для старых браузеров и для браузеров с классом .no-cssgrid.

float: left;

Способы адаптации

  • CSS-префиксы: -webkit-, -moz-, -ms-, -o-.
  • Фолбэк на основе float.
  • Проверка поддержки через @supports.
  • Проверка поддержки через библиотеку Modernizr (классы .cssgrid / .no-cssgrid на <html>).
  • Адаптация под мобильный экран через медиазапрос.

Вывод

Современные браузеры используют удобную Grid-сетку. Старые браузеры получают более простое оформление через float, но содержимое остаётся читаемым и доступным.
